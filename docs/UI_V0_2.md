# v0.2.0 화면 구조와 지도 연동 결정

구현 전 검토: 2026-11-15. 기존 Journey.kt와 22개 JourneyTest는 유지한다.

## 화면 구조

| 영역 | 세로·좁은 창 | 가로·넓은 창 |
|---|---|---|
| 상단 | 브랜드, 시연 표시, 설정, D/P/M 단계 | 동일, 여백 확장 |
| 지도 | 본문 높이의 약 32%, 최소·최대 높이 적용 | 왼쪽, 남는 공간 사용 |
| 안내 | 하단 카드, 본문만 스크롤 | 오른쪽 카드, 본문만 스크롤 |
| 주요 버튼 | 카드 하단 고정 | 패널 하단 고정 |

단계별 내용은 계획(시설·동행 조건), 하차(명시적 확인), 주차(명시적 확인), 재합류(고정 만남 장소)다. 지도 인스턴스는 단계 변경 때 재생성하지 않는다. 체크 선택으로 화면 전체를 교체하지 않는다. 지도 마커는 세 가지 상세 정보를 열며, 상태 머신을 임의로 진행시키지 않는다.

네이비 텍스트, 화이트 패널, 블루 주요 동작을 사용한다. 반응형 분기는 장치 이름이 아닌 실제 앱 창 크기를 기준으로 한다. 시스템 상태·내비게이션 영역을 숨기지 않으며 Pleos Driving view를 덮지 않는다. 회전·멀티윈도우에서는 여정을 유지하고, 백그라운드 전환 시 안전 확인은 해제한다.

## 지도 공급자

KakaoMaps Android SDK 2.15.2는 공식 문서상 ARM(armeabi-v7a, arm64-v8a)과 OpenGL ES 2.0 이상을 지원한다. x86_64 Pleos 에뮬레이터에 ARM 네이티브 라이브러리를 억지로 설치하지 않는다.

- `offline`: 네이티브 SDK가 없는 호환 APK. x86/ARM에서 샘플 동선과 D/P/M 상세 보기를 제공한다.
- `kakao`: 실제 SDK를 포함한 ARM APK. 네이티브 앱 키가 없거나 인증·렌더링에 실패하면 샘플 동선으로 전환한다.
- `demo`/`pleos` 차량 신호 변형은 지도 공급자와 독립적이다.

실제 지도 타일, UI 시연용 D/P/M 좌표, 내비게이션 요청은 각각 구분한다. 가상의 A병원/B쇼핑몰을 실제 시설로 등록하거나 검증된 하차 구역이라고 주장하지 않는다. 샘플 마커의 좌표는 실제 시설 정보가 아니며 실제 경로 요청으로 전달하지 않는다.

## 확인할 항목

실제 스마트폰 세로·가로, 좁은 창/화면 회전 중 여정 유지, 큰 글꼴과 스크롤, 마커 상세, 주행 잠금, 기존 8개 UI 시나리오, 기존 22개 단위 테스트. API 키가 없는 경우 실제 타일 인증 성공으로 보고하지 않는다.
